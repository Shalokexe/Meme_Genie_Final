## 🌟 4-Phase Memer App Journey

1. **Phase 1: Dynamic Parallax Landing & Login Page**:
   - Scroll-reactive hero with parallax effects, tagline *"MADE BY MEMERS, MADE FOR MEMERS"*, and user authentication modal.
2. **Phase 2: Mandatory 10-Question Meme IQ Quiz**:
   - Tests meme knowledge with 10 questions and calibrates your official **Meme IQ Score** (e.g. *Meme IQ 145 - GigaChad Tier*).
3. **Phase 3: Spotify-Style Meme Taste Selection**:
   - Interactive meme grid rendered in **Black & White** (`grayscale(100%)`). Tapping memes transforms them into **Full Vibrant Color** (`grayscale(0%) scale(1.04)`).
4. **Phase 4: Instagram-Style Main Portal**:
   - Social portal featuring **For You Page (FYP Feed)** with upvoting, **Mind Reader**, **Free Web RAG Search**, **Meme Creator Studio**, **MemeX Stock Exchange**, **Hall of Fame**, **Match Arena**, and **Profile**.

## ⚡ Quickstart Guide

```bash
# 1. Install Dependencies
pip install fastapi uvicorn pymongo pydantic

# 2. Launch Backend Server
uvicorn backend.main:app --reload --port 8000
```

Open **`http://127.0.0.1:8000/`** to experience **Meme Genie v5.0.0-Beta**!
