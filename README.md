## 🌟 Human-Crafted Minimalist Interface

**Meme Genie** features a serene, minimalist dark interface inspired by modern design standards (Linear, Vercel, Raycast, Apple dark mode). Every panel is structured with clean typography (`Inter`), subtle frosted borders (`rgba(255,255,255,0.08)`), and generous breathing room.

## 🔥 Key Features

### 🔮 1. AI Mind-Reading Engine
- **Entropy Tag-Scoring Matrix**: Asks strategic binary trait questions (music, era, trolling, global popularity, animals, face reactions, gaming).
- **Web Speech AI Voice**: Voice synthesis and voice command recognition.

### 📈 2. MemeX Virtual Stock Exchange (Meme Economy)
- **Trade Meme Stock Shares**: Buy and sell shares in viral internet memes using virtual MEME coins to build your investment portfolio.
- **Dynamic Price Fluctuation Engine**: Prices update based on player trade volume and simulated internet trends.

### 🏆 3. Immortal Meme Hall of Fame & Longevity Analytics
- **Internet Usage Duration**: Displays exact viral lifespan metrics (*e.g. Rickroll: 19 Years Virality, 2007 – Present*).
- **Golden Community Upvotes**: 1-Click community upvoting for Hall of Fame memes.

### 🔍 4. Free RAG Web Search Engine & Grok AI Integration
- **Live Web Retrieval**: Search any meme or catchphrase live from the web for free (DuckDuckGo scraper + Grok AI `xAI` API fallback).

### 🎨 5. In-App Meme Creator Studio
- **HTML5 Canvas Meme Editor**: Classic Impact meme typography with 1-click publishing and PNG exporter.

## ⚡ Quickstart Guide

```bash
# 1. Install Dependencies
pip install fastapi uvicorn pymongo pydantic

# 2. Launch Backend Server
uvicorn backend.main:app --reload --port 8000
```

Open **`http://127.0.0.1:8000/`** to play **Meme Genie 🧞‍♂️**!
