## 🌟 What's New in v5.1.0-Beta

### 📹 1. MemeTV Random Stranger Video Roulette (Omegle for Memers)
- **1-on-1 Video Chat**: Match live with random strangers matched by their calibrated **Meme IQ Level**.
- **WebRTC PeerConnection**: Low-latency HTML5 video/audio streams with WebSocket signaling.
- **Controls**: `⚡ Start Searching`, `➡️ Next Stranger`, `🛑 Disconnect`.

### 📱 2. Site-Wide Responsive Layout Resizing
- Comprehensive `@media` breakpoints for mobile (375px+), tablet (768px), and ultra-wide screens.
- Aspect ratio constraints (`aspect-ratio: 16/9`) preventing image/video overflow.

## ⚡ Quickstart Guide

```bash
# 1. Install Dependencies
pip install fastapi uvicorn pymongo pydantic

# 2. Launch Backend Server
uvicorn backend.main:app --reload --port 8000
```

Open **`http://127.0.0.1:8000/`** to experience **Meme Genie v5.1.0-Beta**!
