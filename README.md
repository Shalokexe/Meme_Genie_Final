## ⚡ Quickstart Guide

### 1. Install Dependencies
```bash
pip install fastapi uvicorn pymongo pydantic
```

### 2. Launch Backend Server
```bash
uvicorn backend.main:app --reload --port 8000
```

### 3. Play Meme Genie!
Open your browser and navigate to:
```
http://127.0.0.1:8000/
```
